# Проверка одного цеха и жизненного цикла

Дата: 2026-10-05. ADR: [0004](adr/0004-optional-workshop-contract.md).

## Проверенное поведение

- В новом мастере и старом API подтверждения номер договора больше не обязателен. Отсутствующие номер/дата остаются пустыми; изменение карточки цеха не переписывает исторический снимок партии.
- В новом сквозном API-тесте единственный Ак Сарай создаётся только с названием. Партия размещается без срока и BOM; повтор возвращает тот же ID и одну спецификацию. Архив скрывает цех из обычного списка и запрещает новую партию; старые связи доступны, восстановление возвращает цех. Некорректный параметр списка даёт 400; отменённый черновик сохраняет модель.
- 43 браузерные проверки в изолированной локальной компании: создание без договора, потерянные ответы и повтор, размеры/цвета, сохранение ввода, приёмка факта, ОТК, закрытие, связи модель/партия/спецификация, отмена владельцем и отказ оператору, архив модели и цеха, очистка ввода, размеры 320/390/430/1440. Ошибок JavaScript нет.
- Полная локальная проверка: 202 теста вне API прошли; 178 из 179 API-тестов прошли, один старый вертикальный сценарий превысил лимит 5 секунд при параллельной нагрузке. Повтор его файла без нагрузки: все 3 теста прошли. Всего проверены 381 тест; финальный обязательный полный прогон выполняет CI конкретного коммита перед публикацией.
- Полные lint, typecheck и build прошли; финальные изменения веб-клиента также отдельно проверены типами, lint и сборкой. Изменений схемы/миграций нет.

## Саморевью

Права чтения/записи цеха не расширены. Запрос архива фильтруется по компании; архив не удаляет записи. Новые заказы проверяют активность цеха сервером. При неизвестном результате отправки очистка недоступна, повтор использует прежний ключ. Цена, количество и юридические реквизиты не подставляются вымышленными значениями. Транзакционность создания и неизменность снимка сохраняются. Новых запросов на каждом кадре, библиотек и миграций нет.

## Границы проверки и публикации

Production не используется для тестовых моделей, партий или удаления реальных данных. Сессия владельца на телефоне агенту недоступна. Полный опубликованный путь проверяется в отдельном Railway preview с тестовым аккаунтом; production — доступность, точные версии клиента/сервера и существующий аудит целостности. Итоговые ID коммитов, CI и deployments, результаты preview и публичной проверки сохраняются отдельно в `garmentos-repair-verification/single-workshop/release-results.json` после публикации.

Notion пока не подключён. [База знаний](NOTION_PROJECT_HUB.md) подготовлена, но не опубликована туда. Матрица всех найденных путей архива/отмены и открытых пробелов — [аудит жизненного цикла](SINGLE_WORKSHOP_AND_ENTITY_LIFECYCLE.md).
