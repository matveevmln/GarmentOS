# ADR 0004: партия без обязательного договора цеха

Статус: принято. Дата: 2026-10-05. Основание: владелец работает с одним цехом Ак Сарай и просит создавать партии без заполнения договорных реквизитов.

## Решение

Единственный активный цех выбирается автоматически. Номер и дата договора, ИНН, адрес и подписанты не являются условием создания или подтверждения партии. Цена, модель, реальные количества и распределение по размерам остаются обязательными; срок можно не указывать.

Снимок партии фиксирует только известные значения: отсутствующий номер договора записывается пустой строкой, без выдуманных реквизитов. Заполнение карточки цеха позднее не переписывает исторический снимок. Запись спецификации создаётся вместе с партией; PDF и отправка остаются отдельными действиями. PDF с пустыми юридическими полями не считается готовым подписанным договорным документом.

Для удаления из рабочего справочника используются существующие статусы архива модели и цеха с восстановлением. Для партии — существующая отмена с причиной и проверкой фактов. Приёмки, остатки, оплаты и оригиналы документов не удаляются каскадом.

## Последствия и проверка

Миграции и новая сущность партии не нужны. Проверяем оба пути подтверждения, создание без норм материалов, повтор сохранения после потерянного ответа, архив/восстановление и сохранность связей. Данные тестов создаются только в изолированной среде. Документация для Notion хранится в GitHub до подтверждённого подключения Notion.
