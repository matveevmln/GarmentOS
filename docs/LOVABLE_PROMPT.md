# Промпт для Lovable / v0 — визуальный референс GarmentOS

> Назначение: получить **визуальный референс** (скриншоты), а не рабочее приложение. Код внешнего генератора в `apps/web` не переносится — берём только внешний вид.
>
> Два варианта промпта. В обоих **одинаково жёстко зафиксированы данные** (реальные поля из `packages/db-schema` и `packages/shared-types`) — это не вопрос вкуса, это защита от выдуманных сущностей. Различаются только степенью свободы по визуалу.

| Вариант | Когда брать |
|---|---|
| **А — свободный** | Хотите увидеть, что предложит генератор сам. Он выбирает тему, палитру, типографику. |
| **Б — заданный** | Хотите тёмное премиальное направление из ранее показанного концепта. |

Разумный ход: прогнать **вариант А два-три раза** (получите разные направления), выбрать понравившееся, и уже его доводить.

## Что делать с результатом

1. Скриншоты по каждому экрану в трёх ширинах (1440 / 768 / 390) — прислать мне.
2. Я сравню с текущим прототипом (`apps/design-prototype/`) и перенесу удачные решения.
3. Если генератор всё же выдумает несуществующие данные — это видно по спискам выше, такие блоки просто не переносим.

**Честное предупреждение по варианту А**: полная свобода означает, что результат может не совпасть с уже собранной дизайн-системой (`apps/design-prototype/tokens.css`). Тогда перенос — это не «поправить цвета», а пересобрать токены и компоненты заново. Это нормально и выполнимо, просто дольше. Вариант Б переносится почти механически.
