# Промпт для Lovable (генерация визуального референса GarmentOS)

> Назначение: получить **визуальный референс**, а не рабочее приложение. Результат — скриншоты, по которым переносится визуальный язык в `apps/web`. Данные и статусы в промпте — настоящие (из `packages/db-schema` и `packages/shared-types`), чтобы Lovable не изобрёл несуществующие сущности.

## Как пользоваться

1. Скопировать блок ниже целиком в Lovable.
2. Дать сгенерировать. Дальше просить по одному экрану: «now show the Batch Passport screen on mobile».
3. Прислать скриншоты — перенесу визуальный язык в прототип и `apps/web`.
4. **Код Lovable не переносим** — берём только внешний вид.

## Что делать с результатом

1. Скриншоты (desktop 1440 + mobile 390 по каждому экрану) — прислать мне.
2. Я сравню с текущим прототипом и перенесу удачные решения: типографику, плотность, тени, композицию.
3. Если Lovable всё же выдумает несуществующие данные — это будет сразу видно по списку выше, и такие блоки просто не переносим.
